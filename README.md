# MSC Music Pack Builder — Backend

Реальний сервер: приймає аудіофайли, конвертує їх у `.ogg` через **FFmpeg**, накладає
пресети звучання (Old Radio, Cassette, Car Stereo, Vintage, Old Speaker) — тільки для
Premium, генерує текстури диска/коробки (PNG) і повертає готовий ZIP. Перевірено
локально: конвертація, ефекти, текстури та Free-ліміти працюють.

## Що вже реально працює

- `POST /api/build` — приймає файли (`multipart/form-data`, поле `files`, в потрібному
  порядку), параметри `mode` (`music`/`radio`), `processing` (id пресету), `generateTexture`
  (`true`/`false`), `titles` (JSON-масив назв треків) — і одразу стрімить у відповідь готовий
  `MSC_Music_Pack.zip`.
- `GET /api/health` — перевірка, що сервер живий.
- Сервер **сам** перевіряє ліміти файлів і Premium-статус — фронтенду тут не довіряємо.
- Тимчасові файли на диску видаляються одразу після відповіді.

## Що поки спрощено (наступні кроки, не зараз)

- Premium перевіряється одним спільним ключем (`PREMIUM_KEY` у `.env`), без акаунтів —
  це тимчасова заглушка, поки немає бази даних і оплати.
- Немає перевірки "магічних байтів" файлу (лише розширення) — можна додати пізніше
  пакетом `file-type`.
- ffmpeg-обробка одного запиту синхронна — для дуже великих пакетів (десятки файлів)
  варто буде винести в чергу (BullMQ + Redis), але для старту цього не треба.

## Запуск локально

```bash
npm install
cp .env.example .env
# постав будь-який ffmpeg на систему, якщо ще нема:
# Ubuntu/Debian: sudo apt install ffmpeg
# Mac: brew install ffmpeg
npm start
```

Сервер підніметься на `http://localhost:3000`.

## Деплой на Render.com (безкоштовно, з нуля)

1. Заведи акаунт на [render.com](https://render.com), увійди через GitHub.
2. Заливай цю папку (`msc-backend`) як окремий репозиторій на GitHub (можна через
   веб-інтерфейс GitHub: New repository → Upload files → перетягни всі файли звідси).
3. У Render: **New → Web Service** → обери щойно створений репозиторій.
4. Render сам побачить `Dockerfile` і запропонує **Environment: Docker** — залиш так
   (це важливо, бо саме Dockerfile ставить FFmpeg, якого немає у звичайному Node-образі).
5. У розділі **Environment Variables** додай:
   - `FRONTEND_ORIGIN` — адреса твого сайту (наприклад `https://msc-pack.netlify.app`)
   - `PREMIUM_KEY` — будь-який довгий випадковий рядок (тримай у секреті)
6. Натисни **Create Web Service**. Перший деплой триває кілька хвилин (збирається
   Docker-образ). Після завершення отримаєш адресу типу `https://msc-backend.onrender.com`.
7. Перевір: відкрий `https://msc-backend.onrender.com/api/health` — має повернути `{"ok":true}`.

> Безкоштовний план Render "засинає" після періоду без запитів і прокидається кілька
> секунд на перший запит — нормально для старту, для реального навантаження згодом
> перейдеш на платний план.

## Наступний крок: підключити до фронтенду

Коли backend буде онлайн — заміни в фронтенд-сторінці локальну "збірку ZIP у браузері"
на реальний запит до `https://<твій-backend>.onrender.com/api/build` (multipart-запит з
файлами у порядку з редактора). Скажи мені адресу свого backend — я підправлю фронтенд,
щоб він реально ходив на сервер.
